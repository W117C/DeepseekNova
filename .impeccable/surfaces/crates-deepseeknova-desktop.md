# Surface brief — 桌面端主窗口（crates/deepseeknova-desktop，待重建）

## 范围与模式
- 范围：桌面端全功能应用（对话 + 会话管理 + run 恢复 + 评分卡/诊断可视化 + 设置），Tauri 2 + SolidJS + Tailwind 4。
- 访客模式：Operate——用户来完成任务（驱动 agent、审批、复盘），可扫描性与状态清晰度优先于表达；观测台语法不得遮蔽任务。

## 受众与任务
- 开源社区开发者 + 维护者；日常驱动 AI 编码 agent，实时审阅流式输出，对权限请求做批准/拒绝，事后查看 run 质量。
- 证据/内容：全部来自真实后端（SSE 事件流、runs 落盘、评分卡/诊断 JSON），无需编造。

## 已选方向与批准记录
- 视觉世界：**新星观测台 Nova Observatory**（用户 2026-08-07 第二轮拍板，推翻第一轮 canon）——Agent 会话即一夜观测：流式事件是观测记录，审批是圆顶联锁，评分卡是测光曲线。工艺基准线 Claude Desktop / Claude Code。
- 批准构图（两稿同轮选定）：主窗口北极星 = `.impeccable/mocks/obs-comp-b-workbench.png`（sidecar `approved: true`）——观测工作台拓扑：左侧按夜次分组的观测日志会话栏 + 顶部"观测之夜" runs 条带 + 中央划线日志对话流 + 右侧双图框（run 事件星座图 / 六维测光评分卡）。观测日志视图 = `.impeccable/mocks/obs-comp-a-log.png`（sidecar `approved: true`）——圆顶状态带 + 夜次分组会话栏 + 划线日志流 + 右缘竖向时间线标尺（事件星点 + 底部预算刻度），用作全部 runs 归档/日志页。
- 难忘时刻：**run 事件链画成星座**——事件是星等大小不一的星点，细线连成本次观测的星座，点击星点跳转对应日志条目；评分卡以测光表语法呈现。
- 落选记录：C（红光联锁焦点）落选；C 的整卡红光语法明确否决，审批卡以克制的危险语义（细红边框 + 风险标签 + 红实心允许键仅用于非只读/危险级）在世界内设计。

## 保真度清单（build 时对照，finish reviewer 依此审计）
组件语法：图框（chart frame）= 1px 细边框 + 8px 圆角 + 左上角小标题；发丝刻线分层，无阴影；整窗极淡 graticule 网格底纹；flat matte，无渐变无辉光。
类型坡度：UI 系统 sans 栈（SF Pro/Noto Sans SC 等）；数据/命令/时间戳一律 mono + tabular-nums；正文 14px，标签 11-12px，会话标题 13px，面板标题 12px 大写间距。

| 区域/元素 | 构图承诺 | 实现介质 |
|---|---|---|
| graticule 底纹 | 整窗极淡坐标细线网格（弧线可选），不干扰阅读 | CSS/SVG 背景，透明度 ≤6% |
| 左侧观测日志栏（~1/5 宽） | 夜次日期分组头「08-07 夜」+ 条目星点（星等=活跃度，2-4px 三档）+ 活跃项细圆角靛蓝框 | HTML/CSS |
| 观测之夜 runs 条带 | 细圆角 chip：绿✓已完成 / 琥珀⏸已中断+↻ / 靛蓝●运行中 +「全部 runs →」 | HTML/CSS |
| 对话流 | 划线日志条目：角色标签+mono 时间戳右对齐、dim 斜体「▸ 推理过程」折叠行、工具记录为可展开划线表格行、diff/代码块 | HTML/CSS + shiki |
| composer | 细圆角图框 + `❯` 提示符 + 模型 chip + token 刻度 | HTML/CSS |
| 本次观测（星座图） | run 事件为靛蓝星点（大小=事件权重、颜色=状态），细线连成星座路径，节点 mono 微标签，运行中节点脉动；点击节点滚动到对应条目 | SVG（交互，代码绘制，禁用 raster） |
| 测光·评分卡 | 六行光度表：治理/验证/反思/审查/协议/综合，细靛蓝横条 + mono 右对齐分值，综合行 accent 强调 | HTML/CSS/SVG |
| 审批卡（构图外，继承规范） | composer 上方停靠：细红边框 #D5484F、「权限请求」+ mono 命令 + 风险标签（只读/非只读/危险）、允许/拒绝/仅本次 | HTML/CSS |
| 主要动作「新会话」 | 品牌蓝 #4D6BFE 实心按钮 | HTML/CSS |
| 图标 | 1.5px 细线 stroke 一族 + 世界字形（圆顶、星点、星座） | 图标库（Lucide 类）+ 自绘 SVG 世界字形 |
| 应用 logo/glyph | 构图中为星形占位 | 缺失资产——另行立项，禁止临时编造 |

星座图密度承诺：典型 run 6-14 个节点铺满图框 2/3 面积，路径跨越整框而非缩在角落；空 run 显示空 graticule + 「等待首个事件」。

## 不得字面照抄的部分
- 构图内所有数字（分值 92.3/94.7、时间戳、成本、bench 输出、run 编号）均为合成演示数据。
- 构图 B 星座图的具体节点标签（plan/edit/run_tests…）示意事件类型，以真实 RunEvent 词表为准。
- 侧栏底部「深色模式」开关位置可并入设置；不强制照抄。

## 约束与未决
- 品牌蓝 #4D6BFE 为唯一 accent 星色；琥珀 #E8A33D 仅作标注；绿/红仅作状态语义（红即"红光"危险语义）。
- 深色「夜空」为旗舰默认；浅色主题为「印刷星图」（纸白底 + 墨线 + 深化品牌蓝），语义完整对等。
- 未决：界面文案语言（当前中文 vs 英文/i18n）——实现前由用户定。
- 后端缺口：会话级 HTTP API、本地回环认证——桌面端全功能的配套后端工作（已确认先行补齐）。
