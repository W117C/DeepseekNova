## 变更分组

### 1. TaskSpec 核心类型（agent crate 新文件 `src/task_spec.rs`）
- `TaskSpec { name, task, rules: Vec<String>, inputs: Vec<InputSpec>, tools, max_steps }`
- `InputSpec { name, ty: InputType(String/Number/Boolean), required, default: Option<String> }`
- `InputValues(HashMap<String,String>)`：`From<HashMap>`、`merged_with(over)`（self 优先，over 只补缺）
- `RenderedTask { task, rules }`；`render(&self, &InputValues) -> Result<RenderedTask, TaskSpecError>`
- `TaskSpecError`（thiserror）：MissingRequired/UnknownInput/InvalidType
- **render 规格（实现期无决策空间）**：
  1. 扫描 `task` 收集 `${{ inputs.<name> }}` 引用集合；引用未声明 → UnknownInput（报第一个）
  2. 逐输入求值：values 有 → 用之；否则 default → 用之；否则空串；`required && values 缺 && default 缺` → MissingRequired
  3. 对 values 提供与 default 的值做类型校验（Number 需 `parse::<f64>()` 成功；Boolean 为 "true"/"false"）→ InvalidType
  4. 逐输入 `str::replace` 占位符；替换仅对声明过的输入执行
- 占位符解析手写扫描，不引入 regex 依赖

### 2. DelegatePreset 改造（agent crate `src/delegate.rs`）
- 结构改为 `{ name, system_prompt: String, spec: TaskSpec, config_inputs: InputValues }`；tools/max_steps 移入 spec，system_prompt 保留平铺（Agent 构造期注入用）
- `DelegatePreset::simple(name, system_prompt, tools, max_steps)`：task/rules/inputs 全空的 spec（内置 4 preset 走此路径）
- `DelegateEngine::run(&self, agent, goal, values: &InputValues)`：`full = config_inputs.merged_with(values)` → `render(&full)` → prompt = goal 后按序追加非空 task、非空 rules（`join("\n\n")`）；render Err → anyhow 传播
- 装配逻辑（`for p in &presets` 段）字段路径改 `p.spec.tools` / `p.spec.max_steps`，system_prompt 注入不变

### 3. SubAgentRunner（agent crate `src/sub_agent.rs`）
- `SubAgentConfig { name, system_prompt, spec: TaskSpec, config_inputs: InputValues }`；现有 builder（new/with_tools/with_max_steps）委托 spec，新增 `with_task_spec` / `with_config_inputs`
- `parse_input` 扩展：`input:<name>=<value>` 行（须在 `goal:` 行之前；无 `=` 或空 name 忽略）；返回 `(Option<String>, String, InputValues)`；无 input 行时 values 为空（旧协议不变）
- `run_stream`：`full = config_inputs.merged_with(parsed.values)` → render Err 直接返回 Err；System 消息 = system_prompt + 非空 rules（`"\n\n"` 连接）；User 消息 = goal + 非空 task

### 4. delegate 工具 schema（tools crate `src/delegate.rs`）
- `DelegateArgs` 加 `inputs: Option<HashMap<String,String>>`（serde default）
- schema 加 `inputs` 参数：`{"type":"object","additionalProperties":{"type":"string"}}`，description 说明 `${{ inputs.x }}` 占位符
- execute：构造 InputValues → `run(agent, goal, &values)`；render 错误转友好文本（含原因 + Available agents，模型可自愈）

### 5. 配置（config crate `src/lib.rs`）
- 新增 `InputOverride { name: String, value: String }`（serde 默认无默认值）
- `DelegateAgentOverride` 加 `inputs: Option<Vec<InputOverride>>`；文档注释：仅对已声明 inputs 的 preset 生效，simple preset 的多余键被忽略

### 6. runtime 合并逻辑（runtime crate `src/lib.rs`）
- `merged_delegate_presets`：覆盖分支加 `ov.inputs → p.config_inputs`（转 InputValues）；新增分支构造完整 DelegatePreset（含空 config_inputs）
- `build_delegate_engine`：`p.tools` → `p.spec.tools`，`p.max_steps` → `p.spec.max_steps`
- `build_sub_agent_runner`：`p.tools` → `p.spec.tools`，`p.max_steps` → `p.spec.max_steps`，追加 `.with_config_inputs(p.config_inputs.clone())`
